# PetViva 🐾

Uma vitrine de loja pet responsiva, feita com HTML, CSS e JavaScript puro.

## Estrutura

```
pet/
├── index.html       # Estrutura da página
├── styles.css       # Estilos e responsividade
├── script.js        # Produtos, filtros e carrinho
├── README.md        # Documentação
└── assets/
    └── .gitkeep     # Pasta reservada para imagens locais
```

## Como visualizar

Abra `index.html` no navegador ou publique com GitHub Pages em **Settings → Pages**.

## Funcionalidades

- Catálogo com filtros por categoria e busca.
- Carrinho com quantidades, remoção e subtotal.
- Layout responsivo para celular e desktop.
- Formulário demonstrativo de newsletter.

## Antes de vender de verdade

Os produtos, preços e imagens são exemplos. O checkout e o cálculo de frete precisam ser integrados a um provedor de pagamento e logística. Atualize os dados comerciais e o contato da loja. As imagens são carregadas de URLs externas do Unsplash.
